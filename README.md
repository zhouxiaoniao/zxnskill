## 📖 项目简介

这是一个基于商业控制论、大商业物理法则与反人性弱点的**数字化商业体检与心智粉碎系统**。

我们拒绝市面上所有温吞、虚伪的鸡汤和廉价的教条。  
它的唯一使命：**在一个人把手里的血汗钱送给房东、加盟商、培训班之前，用三句话把他抽醒，告诉他他到底是在赚钱，还是在给社会送人头。**

> **我是周小鸟。请你开始提问。随便问什么，让我们开始就好。**

## 🛠️ 用户提问的三种姿势

1. **测生意/副业能不能赚**：  
   *“我想辞职在小区楼下开精酿酒馆，一杯卖40，能干吗？”*
2. **测做自媒体卡在哪**：  
   *“我发了30条小红书，播放量全卡在500突破不了，死在哪了？”*
3. **帮文案/选题做质检**：  
   直接把草稿扔进来：*“帮我看看这段话及不及格，死穴在哪，怎么改？”*
