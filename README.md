## 这是什么

`zxnskill` 是周小鸟整理的商业与内容自查工具包。把提示词或知识库装进你常用的 AI 对话工具后，可以直接在对话里使用。

当前已上线 **模块 01（商业底座与问题排查）**，装好后你可以用它：

* 判断一门生意、副业或项目在“货源来源、目标人群、物理账本”上是否成立
* 检查正在做的项目或账号卡在哪一步，找出明天就能验证的最小动作
* 提前排查常见违法红线、假需求自嗨和无效动作

方法底稿整理自周小鸟的商业底层文稿（`knowledge_base/01~07`）与实战纠偏记录（`knowledge_base/08`）。

## 如何安装

按你使用的工具任选一种方式：

### 方式一：单文件快速使用（豆包网页版 / DeepSeek / Kimi / ChatGPT / Claude）
1. 打开仓库里的 [System_Prompt.md](System_Prompt.md)，全选复制内容。
2. 粘贴到你常用 AI 工具的「系统提示词 / 智能体设定」中，或直接作为新对话的第一句发送。

### 方式二：Agent 一键识别 / 完整知识库挂载（豆包桌面端 / WorkBuddy / Claude Code / 扣子 / Dify）
* **支持 Skills 的 Agent（如豆包桌面端、Claude Code 等）**：直接把仓库地址 `https://github.com/zhouxiaoniao/zxnskill.git` 发给它让它安装，根目录已内置标准 [SKILL.md](SKILL.md) 入口。
* **手动挂载知识库（扣子 Coze / Dify / GPTs / Claude Projects）**：将 `knowledge_base/` 目录下的全部 8 个 `.md` 文件导入知识库，再把 [System_Prompt.md](System_Prompt.md) 填入人设/系统指令栏。

## 如何使用

### 1. 开始对话
安装完成后发一句“你好”或“你是谁”，工具仅会回复一句极简开场，随后即可直接提问。

### 2. 怎么提问结果更准
直接写出你的具体做法、手头现状和问题。**信息不用很整齐，但尽量带上真实数字**，例如：

```text
我想在县城小区门口开一家早餐店，租金一年 4 万，手里一共 10 万本金，没做过餐饮，能干吗？
```

```text
我在网上花 99 元买了一批行业资料合集，准备在小红书卖 9.9 元一份引流，这套路行得通吗？
```

```text
我发了 30 条账号图文，平均播放卡在 500 左右，目前主要是拍日常感悟，不知道死在哪一步了？
```

提问时附上以下信息，诊断会更准确：
* 你手头上已有的事实和数字（成本、售价、预算、人数、成交情况）
* 具体的货源或交付方式（货从哪里来、怎么收钱）
* 遇到稿件自查时，请给完整文案，不要只给几句摘要

### 3. 在同一个对话里继续
收到结果后，如果系统向你追问具体细节，直接在同一个对话里补充真实情况即可。换一个新项目时，再新开对话提问。
