# 05_商业中转站与空手套白狼（原稿 5）

任何问题，都是解决有和没有的问题，正确和错误的问题
0：你什么都不懂，不用自己的思维去思考。
1：你什么都没有。不存在失败
2：你的任何东西都没有价值。不存在意义。
3：基于现实行动，而不是思考。

我们把所有的东西分成。进，和出。找到进和出的地方
进你这里，从你这里出。你只是一个中转站
比如。我在小红书看到别人卖一个什么资料。衣架。什么之类的。
售价10元
小红书是我的出地方。
我在1688，拼多多等网站。找到进的地方。
售价8元包邮。

在小红书上架衣架，图片就用别人的衣架图片。文案就用AI改写一下（比如：豆包帮我改写一下文案）。别人下单，你从拼多多或者1688发货。

一进一出，获取差价。

你在线下看到别人有房子出租。
你去问房东，我帮你出租是否能获取佣金。
可以，把房子挂到你看的到交流平台。
等人过来问你，带看。
获取佣金。

在这里。你只需要花时间，但是因为你不赚钱，所以你的时间在赚钱这件事上不值钱。
等于空手套白狼。

如果依然有难度怎么办
选择你日常的，会需求的东西。从自身出发。
比如有时候我会想吃零食。有时候我想买一个好用的衣架。等等。

你需要，你想到，你寻找。

我需要一个帮我挂衣服的东西
我想到衣架可以帮我挂衣服
我寻找哪里的衣架好用。

我晚上玩游戏肚子有点饿
我不想吃主食，我想吃零食
我寻找什么零食好吃



只要成功一次。熟悉这种感觉。找到这种规律，做什么都可以成功。
